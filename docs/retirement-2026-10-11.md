# Factory retirement — 11 October 2026

At the owner's request, Factory is considered a failed project for now and development is suspended. This is a preservation and local cleanup operation, not a release or a claim that the product met its goals.

The complete latest Factory development history is retained on the GitHub branch `codex/runtime-recovery-20261007` in [EnoughFactory](https://github.com/enoughtools/EnoughFactory). The existing main branch and release history remain available.

Factory's generated native mail-client source is retained separately in the private [enoughmail-device repository](https://github.com/enoughtools/enoughmail-device). Its main branch preserves the integrated source. Recovery branches preserve candidate versions, relevant supporting source, workspace tips and unfinished contract edits. These branches are historical work, including unsuccessful attempts; they do not establish completion or passing verification.

A compact private local retirement folder retains the compressed coordinator database, source-recovery mappings and selected reports and capture records. Device credentials, provider authentication, raw provider histories and runtime configuration are not published to GitHub.

Local cleanup removes the EnoughFactory desktop app, its owned runtime and VM, generated environment storage, provider-history copies, development dependencies and build caches. Other installed apps, project repositories and the user's independently managed container runtime are outside this cleanup.
